# ИИ-Открытка: Код, Оживающий в Пикселях! 🎉🤖

**ИИ-Открытка** — это твой билет в ретро-футуристический мир поздравлений! Создавай уникальные открытки с ИИ-вайбом, 8-битным пиксель-артом и нейронными сетями, которые танцуют на экране. Персонализируй имя, пожелание и хобби, выбирай яркие градиенты и анимации текста — и пусть твой код поздравляет с душой!

## Почему это круто?
- **Пиксель-арт**: 8-битные спрайты (компьютер, геймпад, гитара, мяч, кисть) с анимацией, вдохновлённой твоими хобби.
- **Персонализация**: Добавь имя, пожелание и интересы — от программирования до музыки!
- **Градиенты**: 7 космических тем (сине-фиолетовый, розово-голубой, закатный и др.).
- **Анимации текста**: Glitch, Typewriter, Neon, Pixel Pulse — пиксельная магия!
- **Нейронная сеть**: Динамические узлы и связи, будто ИИ сам рисует открытку.
- **Экспорт**: Скачай открытку в PNG.
- **Адаптивность**: Идеально для десктопов и мобильных (включая OPPO CPH1931).

## Установка
1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/ваш-юзернейм/ai-birthday-card.git
   ```
2. Открой `index.html` в браузере или используй **Live Server** в VSCode:
   - Установи расширение `Live Server` (Ctrl+Shift+X).
   - Правый клик на `index.html` → "Open with Live Server".

## Как создать шедевр
1. Введи имя (например, "Алекс"), пожелание ("Кодируй без багов!") и хобби ("программирование").
2. Выбери градиент и анимацию текста (Glitch, Neon и др.).
3. Кликни "Создать Открытку" — твоя пиксельная магия готова!
4. Нажми "Скачать Открытку" для сохранения в PNG.

## Развертывание на GitHub Pages
1. Создай репозиторий на GitHub и загрузи файлы:
   ```bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```
2. В настройках репозитория → Pages → выбери ветку `main`, папку `/ (root)`.
3. Открытка оживёт по адресу: `https://ваш-юзернейм.github.io/ai-birthday-card`.
